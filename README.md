# 지문.zip

영어 내신 지문을 한눈에 정리하다.

## 프로젝트 소개

지문.zip은 영어 내신 시험을 준비하는 학생이 많은 지문을 빠르게 정리하고 복습할 수 있도록 만든 웹앱입니다. 영어 지문을 직접 입력하거나 사진으로 업로드하면 AI가 지문의 제목, 논리적 흐름, 핵심 주제문장, 중요 단어·문법, 핵심 키워드를 일정한 형식으로 분석합니다. 분석한 지문은 시험범위에 저장하여 다시 확인할 수 있습니다.

## 사용법

1. 지문 입력 방법을 선택합니다.
2. `직접 입력`을 선택한 경우 영어 지문을 입력합니다.
3. `사진 업로드`를 선택한 경우 영어 지문 사진을 업로드하고 지문 영역을 선택합니다.
4. `지문 분석하기`를 눌러 AI 분석 결과를 확인합니다.
5. 필요한 지문은 `시험범위에 저장`하여 시험 전에 다시 확인합니다.

## 주요 기능

- 영어 지문 직접 입력
- 영어 지문 사진 업로드 및 지문 영역 크롭
- AI 기반 지문 분석
- 논리적 흐름 및 핵심 주제문장 확인
- 중요 단어·문법·핵심 키워드 확인
- 영어 원문 확인
- 시험범위 저장 및 삭제
- 시험범위 브라우저 저장
- 입력 및 AI 분석 오류 안내
